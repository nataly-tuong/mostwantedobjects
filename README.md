mostwantedobjects

🔗 https://mostwantedobjects.vercel.app/

turns random objects into wanted posters. hit generate, it grabs a random piece from the cleveland museum of art and puts it on a wanted poster with a random crime

what i learned

- how to manage state in react so the poster updates live as i type
- useeffect for fetching: load the object list once on mount, then just pick randomly from it
- why caching the list beats re-fetching on every click
- filtering and mapping api data into a shape my components can use

built with

react, tailwind, vite
